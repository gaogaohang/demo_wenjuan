# 后端开发完成总结

## 项目概述

本项目已完成情侣互动平台后端核心功能开发，采用 Spring Boot 3.2.1 + MyBatis Plus 3.5.5 架构，实现了问卷管理、订单评价和消息通知三大核心模块。

## 技术栈

- **后端框架**: Spring Boot 3.2.1
- **ORM框架**: MyBatis Plus 3.5.5
- **数据库**: MySQL 8.0
- **缓存**: Redis
- **安全**: Spring Security + JWT
- **文档**: SpringDoc OpenAPI (Swagger)
- **工具**: Lombok, Jackson

## 架构简化

- ✅ 移除 JPA，改用 MyBatis Plus
- ✅ 移除 MinIO，改用本地文件存储
- ✅ 移除 Docker 配置，支持直接运行 jar 包
- ✅ 移除邮件、短信、微信等第三方集成

## 启动步骤

### 1. 数据库准备

```bash
# 创建数据库
mysql -u root -p < database/schema.sql

# 插入初始数据（可选）
mysql -u root -p couple_platform < database/init-data.sql
```

### 2. 修改配置

编辑 [backend/src/main/resources/application.yml](file:///c:/Users/Administrator/Videos/demo_wenjuan/backend/src/main/resources/application.yml)：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/couple_platform?useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: your_password

couple:
  jwt:
    secret: your-jwt-secret-key
```

### 3. 编译打包

```bash
cd backend
mvn clean package -DskipTests
```

### 4. 运行应用

```bash
java -jar target/couple-platform-1.0.0.jar
```

### 5. 访问应用

- **API地址**: http://localhost:8080/api
- **Swagger文档**: http://localhost:8080/api/swagger-ui.html

## 前端对接建议

### 认证流程
1. 调用 `/auth/register` 或 `/auth/login` 获取 Token
2. 将 Token 存储在 localStorage
3. 所有请求在 Header 中添加 `Authorization: Bearer {token}`

### 问卷模块对接
- 使用 `/surveys/created` 获取创建的问卷列表
- 使用 `/surveys/target` 获取待填写的问卷列表
- 问卷答案数据格式为 JSON 字符串，key 为问题ID，value 为答案

### 订单模块对接
- 订单状态流转：pending → accepted → processing → completed
- 只有接收者可以更新订单状态
- 只有创建者可以取消订单
- 已完成的订单可以评价

### 消息模块对接
- 建议实现消息轮询（每30秒一次）获取未读数量
- 点击消息时自动标记为已读
- 不同类型消息使用不同图标和颜色区分
