# 项目熟悉笔记

## 项目定位
- 情侣互动平台，核心是「点单」+「问卷」+「消息通知」
- 前后端分离：后端 Spring Boot，前端 Vue 3（移动端为主）
- API 基础路径：`/api`（见 `backend/src/main/resources/application.yml`）

## 目录结构速览
- `backend/`：Spring Boot 后端
- `frontend/`：Vue 3 + Vite 前端
- `database/`：MySQL 建表与初始化数据
- `docs/`：接口与开发文档
- `docker-compose.yml`：Docker 编排（含 MySQL/Redis/MinIO/前后端/NGINX）

## 后端概览

### 技术栈
- Java 17 + Spring Boot 3.2.1
- MyBatis Plus 3.5.5
- MySQL 8 + Redis
- Spring Security + JWT
- SpringDoc OpenAPI（Swagger UI）

### 入口与核心配置
- 入口：`backend/src/main/java/com/couple/platform/CoupleApplication.java`
- 统一响应：`backend/src/main/java/com/couple/platform/utils/ApiResponse.java`
- 配置：`backend/src/main/resources/application.yml`
  - `server.servlet.context-path: /api`
  - 数据源、Redis、JWT、文件上传、日志等

### 认证与权限
- JWT 工具：`backend/src/main/java/com/couple/platform/utils/JwtUtil.java`
- 认证过滤器：`backend/src/main/java/com/couple/platform/security/JwtAuthenticationFilter.java`
- 权限策略：`backend/src/main/java/com/couple/platform/security/SecurityConfig.java`
  - 放行：`/auth/**`、`/swagger-ui/**`、`/v3/api-docs/**`
  - 用户接口：`/user/**`、`/orders/**`、`/surveys/**`、`/messages/**`（ROLE_USER）
  - 文件接口：`/files/**`（ROLE_USER/ROLE_ADMIN）

### 核心业务模块
- 认证（`/auth`）
  - 注册/登录/管理员登录/短信验证码/刷新 Token/登出
  - 短信验证码写入 Redis（`sms:code:*`）
- 用户与配对（`/user`）
  - 个人资料、设置、配对/解绑
  - 配对码在注册时生成（`AuthService.generatePairCode`）
- 点单（`/orders`）
  - 创建/列表/详情/状态更新/取消/评价
  - 状态流转：`pending -> accepted -> processing -> completed`
  - 只有接收方能接单/处理/完成；创建方可取消
- 问卷（`/surveys`）
  - 创建/更新/发布/关闭/删除/详情/我的问卷/目标问卷
  - 状态：`draft -> published -> closed`
  - 回答限制：目标用户 + 允许多次/最大次数/是否过期
- 消息（`/messages`）
  - 发送/列表/详情/标记已读/全已读/删除/未读数
  - 类型：system/order/survey/pair（见数据库注释）
- 文件上传（`/files`）
  - 本地文件存储：`./uploads`
  - 上传通用/头像/订单图片；访问前缀：`couple.file.access-url-prefix`

### 数据模型（核心表）
- users / user_settings / admins
- orders / order_items / order_evaluations
- surveys / survey_questions / survey_responses
- messages
- 额外表（目前代码未看到使用）：push_subscriptions、files、system_settings、operation_logs、视图

### 运行方式
- 本地运行
  - `cd backend`
  - `./mvnw spring-boot:run`
- Swagger UI
  - `http://localhost:8080/api/swagger-ui.html`

## 前端概览

### 技术栈
- Vue 3 + TypeScript + Vite
- Vant UI + Pinia + axios
- `frontend/src/utils/request.ts` 封装了 API 请求

### 路由与页面
- `/login`、`/register`
- 主布局（`/`）：首页、点单、问卷、消息、我的
- 子页面：点单创建/详情、问卷创建/详情/回答、资料编辑、配对

### 状态与数据
